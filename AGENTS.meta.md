# AGENTS.meta.md

This file governs the repository’s root and nested `AGENTS.md` files.

- Keep `AGENTS.md` limited to repository-specific structure, commands, generated files, integration contracts, and concrete operational hazards. Exclude generic working style, personal preferences, approval etiquette, and instructions about how to manage every task or pull request.
- Describe each repository constraint with its actual owner, path, command, or failure mode. Put subtree-specific facts in the nearest nested `AGENTS.md`.
- Verify paths and command names against the checkout. Link to the owning repository documentation rather than duplicating its procedures.
- This repository is public; examples and explanations in agent guidance must not expose private implementation details, credentials, or customer data.
